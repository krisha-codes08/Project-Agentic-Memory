# 🚀 Pathfinder: Conversational AI Career & Academic Agent

[ App link ] https://project-agentic-memory-hxrd4wgxqyu4tgvdlaoko8.streamlit.app/

**Pathfinder** is an advanced, autonomous full-stack conversational platform that orchestrates career guidance and academic tracking using a persistent **MongoDB-backed Agentic Memory Vault**. 

Built explicitly for students and early-career professionals, Pathfinder acts as an intelligent career architect. It dynamically listens to raw natural language chat conversations, extracts core semantic parameters, and updates long-term memory streams to dynamically adjust learning routes, target tracks, and internship checkpoints.

---

## 🌟 Production-Ready Architecture & Core Modules

### 💾 1. MongoDB Agentic Memory Vault
* **Persistent Session Checkpointing:** Utilizes unique identifier tracking (`student_krish_101`) to isolate and retain user profiles across sessions.
* **Sync & Hydrate Engine:** Real-time state recovery mechanism to pull raw memory context arrays directly from database collections instantly on load.
* **Long-Term Memory Vault Inspector:** Visual panel displaying active subcategory states and persistent data payloads extracted directly from natural language interactions.

### 🎯 2. Dynamic Career Pathfinder Timeline
* **Target Stream Alignment:** Auto-categorizes user focus into distinct engineering tracks (e.g., *Core Software Engineering*).
* **Granular Subcategory Extraction:** Leverages parsing rules to drill down goals into specialized domains like *General Systems Architecture*.
* **Adaptive Context Update:** Dynamically tracks the current academic semester status alongside targeted placement pipelines to modify adaptive recommendations.

### 📝 3. Academic Hurdle & Focus Profiler
* **Live Hurdle Flagging:** Active tracking interfaces for multi-course friction mitigation (e.g., *Data Structures & Algorithms*, *Advanced Systems Architecture*).
* **Placement Focus Injector:** Tailors output suggestions directly towards *Baseline Software Engineering applications* or *Performance Tuning portfolios* based on identified skill sets.

### 💬 4. Interactive Agent Conversation Portal
* **Autonomous Parameter Extraction:** Real-time analysis of freeform text to automatically update state structures without rigid input forms.
* **Contextual UI Adaptation:** Automatically shift routing configurations based on conversations regarding backend web dev, deep learning models, computer vision, or cybersecurity.
